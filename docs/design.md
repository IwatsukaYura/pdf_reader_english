 英語PDF Reader アプリ 仕様書

**バージョン:** 1.0  
**作成日:** 2026-02-28  
**プラットフォーム:** Mac デスクトップ

---

## 1. アプリ概要

英語の本を快適に読むための Mac 専用 PDF リーダー。翻訳・単語保存・メモ機能に特化し、Notion と連携して学習をサポートする。

---

## 2. 技術スタック

| レイヤー | 採用技術 | 理由 |
|---------|---------|------|
| デスクトップフレームワーク | **Electron** | Mac ネイティブアプリ化、ローカルファイル操作が容易 |
| フロントエンド | **React + TypeScript** | コンポーネント管理しやすく型安全 |
| PDF レンダリング | **PDF.js** | 高品質なレンダリング、テキスト選択・アノテーション対応 |
| スタイリング | **Tailwind CSS** | 高速なUI構築 |
| 翻訳 API | **DeepL API**（無料枠: 500万文字/月） | 日英翻訳の精度が高い |
| 単語辞書 | **Free Dictionary API** | 品詞・例文の取得（無料） |
| 外部連携 | **Notion API** | 単語帳データベースとして管理 |
| データ保存 | **ローカル JSON** | アノテーション・設定をPDFと同ディレクトリに保存 |

## 4. 機能仕様

### 4.1 PDF 閲覧（標準機能）

| 機能 | 詳細 |
|------|------|
| ファイルを開く | ドラッグ&ドロップ または メニューから選択（複数PDF管理は将来対応） |
| ページ移動 | 矢印キー / クリック / ページ番号直接入力でジャンプ |
| ズーム | Cmd+ / Cmd- / フィットページ / フィット幅 |
| 目次ナビゲーション | サイドバーに PDF アウトライン表示、クリックでジャンプ |
| 保存 | **Cmd+S** でアノテーション情報を JSON ファイルに保存（`ファイル名.annot.json`） |

---

### 4.2 ハイライト機能

- テキスト選択 → ツールバーまたは右クリックメニューからハイライト追加
- **4色対応:** 黄 / 緑 / ピンク / 水色
- ハイライト済みテキストをクリックして削除・色変更が可能
- ハイライト一覧をサイドパネルから確認・クリックでジャンプ

---

### 4.3 翻訳機能（サイドパネル常時表示）

**動作フロー:**

1. テキストを選択する
2. サイドパネルの翻訳エリアに即時翻訳が表示される（日本語）
3. 単語を選択した場合は品詞・例文もあわせて表示
4. 翻訳履歴を直近5件キープし、見返せる

**API 利用:**

- 翻訳: DeepL API（`/v2/translate` エンドポイント）
- 単語詳細（品詞・例文）: Free Dictionary API（`https://api.dictionaryapi.dev/api/v2/entries/en/{word}`）

**表示例（単語選択時）:**

```
━━━━━━━━━━━━━━━━━━━━
🔤 eloquent
━━━━━━━━━━━━━━━━━━━━
【訳】 雄弁な、表現力豊かな
【品詞】 形容詞 (adjective)
【例文】 She gave an eloquent speech.
         彼女は雄弁なスピーチをした。
━━━━━━━━━━━━━━━━━━━━
[📚 単語帳に保存]
```

### 4.4 メモ・コメント機能（余白・サイドバー型）

**メモの追加方法:**

- PDF ページ左右の余白エリアをクリック → テキスト入力ボックスが出現
- 特定テキストを選択 → 右クリック「メモを追加」でそのテキストにリンクしたメモを追加

**メモの仕様:**

- マークダウン記法対応（太字、リスト、見出しなど）
- メモはページ番号と位置情報とともにアノテーション JSON に保存
- **Cmd+S で保存**（未保存の場合はタイトルバーに `●` を表示）
- メモ一覧をサイドパネルで確認・クリックでジャンプ

**保存ファイル構造例（`book.annot.json`）:**

```json
{
  "version": "1.0",
  "pdfPath": "/Users/.../book.pdf",
  "highlights": [
    { "id": "h1", "page": 42, "text": "eloquent", "color": "yellow", "createdAt": "2026-02-28T10:00:00Z" }
  ],
  "notes": [
    { "id": "n1", "page": 42, "anchorText": "eloquent", "content": "## メモ\n重要な単語。次章にも登場する。", "position": "right-margin", "createdAt": "2026-02-28T10:01:00Z" }
  ]
}
```

### 4.5 単語保存 & Notion 連携

#### 単語保存フロー

1. テキスト選択 → サイドパネルの翻訳表示に [📚 単語帳に保存] ボタンが出現
2. ボタンを押すと以下の情報を自動付与してローカル単語帳に保存:
   - 単語・フレーズ
   - 意味（翻訳）
   - 品詞
   - 例文（辞書APIから取得、なければ選択前後の文章から自動抽出）
   - 出典（PDFファイル名）
   - ページ番号
   - 保存日時

#### Notion データベース構造

| プロパティ名 | 型 | 内容 |
|------------|-----|------|
| 単語 | タイトル | 保存した単語・フレーズ |
| 意味 | テキスト | 日本語訳 |
| 品詞 | セレクト | noun / verb / adjective など |
| 例文 | テキスト | 英語の例文 |
| 例文訳 | テキスト | 例文の日本語訳 |
| 出典 | テキスト | PDFファイル名 |
| ページ | 数値 | ページ番号 |
| 保存日 | 日付 | 保存した日付 |

#### Notion 同期方法

- サイドパネルの単語帳に [Notionに同期] ボタン
- 未同期の単語にはバッジ表示
- 同期済み単語は Notion のページURLをローカルに保持

#### 初期設定（アプリ設定画面）

```
Notion Integration Token: [secret_xxxxxxxxxxxx        ]
Notion Database ID:       [xxxxxxxx-xxxx-xxxx-xxxx-xxxx]
[接続テスト]
```

## 5. キーボードショートカット

| ショートカット | 動作 |
|-------------|------|
| `Cmd+S` | アノテーション保存 |
| `Cmd+O` | PDFファイルを開く |
| `Cmd++` / `Cmd+-` | ズームイン / アウト |
| `Cmd+0` | ズームリセット |
| `←` / `→` | 前ページ / 次ページ |
| `Cmd+G` | ページ番号入力にフォーカス |
| `Cmd+F` | PDF内テキスト検索 |
| `Esc` | テキスト選択解除 / モーダルを閉じる |

---

## 6. 設定画面

- **DeepL API キー** 入力欄
- **Notion Integration Token** 入力欄
- **Notion Database ID** 入力欄
- **翻訳言語** 選択（デフォルト: 日本語）
- **サイドパネルの幅** 調整スライダー
- **自動保存** ON/OFF（デフォルト: OFF）
- **Notion 自動同期** ON/OFF（デフォルト: OFF、手動同期推奨）

---

## 7. データ管理

### ローカル保存

| データ | 保存場所 | 形式 |
|------|---------|------|
| アノテーション（ハイライト・メモ） | PDFと同ディレクトリ | `.annot.json` |
| 単語帳 | `~/Library/Application Support/EnglishReader/` | `vocabulary.json` |
| アプリ設定 | `~/Library/Application Support/EnglishReader/` | `settings.json` |

## 8. 開発フェーズ（推奨）

### Phase 1 — MVP（最小限の動くアプリ）
- PDF 表示・ページ移動・ズーム
- テキスト選択 → DeepL 翻訳 → サイドパネル表示
- ハイライト機能（1色）
- Cmd+S でアノテーション保存・読み込み

### Phase 2 — コア機能追加
- ハイライト多色対応
- 余白メモ機能（マークダウン対応）
- 単語帳（ローカル保存）
- 単語辞書API連携（品詞・例文）

### Phase 3 — Notion 連携
- Notion API 連携・単語同期
- 設定画面の整備
- 自動同期オプション

### Phase 4 — 品質向上
- 目次ナビゲーション
- 翻訳履歴
- PDF内テキスト検索（Cmd+F）
- パフォーマンス最適化（大きなPDF対応）
